# Dawn Sharkk — Unturned 开服器（本地网页版 · 萌新友好版）

作者: **Pippl**

一个纯本地的 Unturned 服务器管理工具，自带免安装 Python，无需安装任何东西，双击即用。
毛玻璃质感界面，毛玻璃质感界面，深色/护眼浅色双主题，全部配置汉化，专为第一次开服的玩家设计。

## 使用方法

1. 双击 `启动开服器.bat` → 打开一个黑色命令框，**不要关它**，里面显示：
   - 网页地址: `http://127.0.0.1:8787`
   - 登录密钥（已自动复制到剪贴板）
2. 自己打开浏览器（Edge/Chrome），输入 `http://127.0.0.1:8787`
3. 登录页直接 **Ctrl+V** 粘贴密钥 → 登录
4. **首次使用会进入两步向导**：
   - 第 1 步 · 选择游戏目录（自动探测 Steam 库里的 U3DS，也可以手动粘贴路径）
   - 第 2 步 · 选择已有存档，或给新存档取名创建（自动生成基础配置、自动分配端口）

> 注意：开服器**不会自动打开网页**，请手动输入网址。命令框显示乱码或报错时截图反馈即可；
> 如果提示"端口被占用"，说明开服器已经在运行，直接开网页就行。

## 关于登录密钥

- 密钥**每次启动开服器都会随机重新生成**（不是固定的），以 bat 命令框里显示的最新密钥为准
- 启动时会自动复制到剪贴板，网页登录直接 Ctrl+V
- 它只用于**登录管理网页**，和游戏进服密码无关（进服密码在「服务器设置」里自己设置）
- 登录状态保持 30 天（重启开服器也不用重新登录）；侧边栏底部有「退出登录」和「关闭开服器程序」

## 操作日志

新增「📜 操作日志」页：自动记录所有用户行为和错误——

- **操作**（绿色）：开服/关服/重启、发送命令、修改保存了哪个文件、开关了哪个选项、创建/切换存档等
- **安全**（蓝色）：登录成功/失败
- **错误**（红色）：命令失败、写入失败、网页请求处理异常（含完整堆栈），排查问题直接看这里

日志保存在开服器文件夹的 `操作日志.txt`（超过 2MB 自动滚动备份），网页里可按类型筛选、清空。

## 关于服务器代码（P2P 联机）

服务器开服后，控制台日志里会出现一行 `Server Code: xxx`。
开服器会自动抓取这串代码，**超大字号显示在仪表盘正中央**，一键复制发给朋友，
朋友在游戏里 `Play → 输入服务器代码` 就能直连加入，**不需要端口映射、不需要公网 IP**。
注意：服务器代码每次开服可能会变化，以最新显示的为准。
如果担心陌生人进服，可在「服务器设置」里设置进服密码（`password`）。

## 主题切换

页面右上角的太阳/月亮动画开关一键切换护眼浅色和深蓝黑夜两套主题（白天=蓝天黄太阳+飘云, 黑夜=星空白月），
选择会自动记忆。也可以用网址参数固定：`http://127.0.0.1:8787/?theme=light`。

Unturned 服务器默认不带 Rocket。到「服务器设置」页底部的 **Rocket 插件框架** 卡片点「一键安装」
(使用游戏自带的 `Extras\Install Rocket.bat`)，装完重启服务器。之后把插件 `.dll` 放进
`Servers\你的存档\Rocket\Plugins`，插件配置会自动出现在「文件管理」。

## 服务器启动参数

在「服务器设置」页底部可配置启动方式（每个选项都有用途说明），改完重启生效：

- 服务器类型不再需要选择：固定使用原版 `+Secureserver` 方式（VAC 反作弊开启）
- 联机只用服务器代码（Steam P2P），不需要 Login_Token、不需要端口映射
- **关服不会误伤游戏**：即使你同时开着 Unturned 游戏客户端，点「关服」也只会关闭服务器进程- `+InternetServer` / `+Secureserver` / `+LanServer` 为官方启动项写法
- `-batchmode` / `-nographics` 无窗口后台运行（推荐默认勾选）
- **原版控制台窗口（推荐开启）**：服务器以原版方式启动，弹出独立的黑色控制台窗口（实时显示全部
  服务器输出，可直接敲命令）；同时输出会同步到网页「运行日志」——**无论是否安装 Rocket 都有日志**。
  关闭开服器或网页后**服务器继续驻留运行**，想关服回来点「关服」或在服务器窗口按 Ctrl+C
- **关闭 bat 窗口时同时关闭服务器**（默认关闭）：打开后，关掉 bat 黑色窗口会自动关闭服务器
- 自定义参数框可追加其他官方启动项

## 重要说明

- **修改配置前请先关服**，改完再开服，否则修改会被覆盖。
- 点「关服」按钮会先自动保存世界再安全关闭；「重启」同样会保存。
- 中文内容按文件原编码（UTF-8 / GBK 自动检测）保存，不会乱码。
- 以后往 `Servers\<你的存档>\Rocket\Plugins` 放插件，插件的配置文件会自动出现在「文件管理」里。
- 想开多个服务器：在向导（侧边栏底部「切换/重设」）里创建多个存档，端口会自动错开。

## 发给朋友前

把整个 `unturned-server-manager` 文件夹发给朋友前，建议删掉里面的 `settings.json`（里面是你电脑的
游戏目录/存档配置），朋友打开后走一遍两步向导即可；`logo.png` 可保留。登录密钥每次启动随机生成，无需处理。

## 联机方式说明

- **服务器代码 P2P 联机（推荐萌新）**：不需要端口映射、不需要 Login_Token，仪表盘复制代码发给朋友即可
- 不填 `Login_Token` 时，服务器不会出现在互联网服务器列表、也无法公网 IP 直连，但代码联机不受影响
- 想让朋友通过 IP / 服务器列表进入，才需要到 steamcommunity.com/dev/managegameservers 申请
  Login_Token 并填入 `Config.txt` 的 Browser 段

## 技术细节

- 开服命令为原版方式：`Unturned.exe -batchmode -nographics +InternetServer/<存档名>`，默认带独立控制台窗口，服务器独立驻留（关掉开服器不影响）
- 网页只监听本机 127.0.0.1:8787，需要密钥登录；开服时临时启用 Rocket RCON
  （密码同样来自 `secret.key`，仅本机连接，关服后自动还原 Rocket 配置）
- 自带 `python` 文件夹（官方嵌入式 Python 3.11），整个文件夹拷到别的电脑也能用
