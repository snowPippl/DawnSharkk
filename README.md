## ✨ 简介

**Dawn Sharkk** 是一个纯本地的 Unturned（U3DS）服务器管理工具。

它自带免安装嵌入式 Python，**无需安装任何东西，双击 `DawnSharkk.exe` 即用**。
所有操作都在浏览器中完成：高端毛玻璃质感界面、深色 / 护眼浅色双主题、
动态极光背景与玻璃拟态弹窗，专为第一次开服的玩家设计，也让老服主省时省心。

- 🏠 服务器开 / 关 / 重启，安全关服自动保存世界
- 🛒 **本机没有开服端？第 1 步就推你去 Steam 商店装** —— `Unturned - Dedicated Server` 完全免费，
  点「🛒 在 Steam 商店打开开服端」只开一个**新标签页**（页面不印网址、当前设置页不会跳走），
  装完点「🔄 重新检测本机」就能选到（v0.1.12 起）
- ⬇️ **不想让它进游戏库？备用的 SteamCMD 一键下载** —— 走 Valve 官方服务器匿名下，包里自带工具，不用另下
- 🚧 **选错目录会被拦下，但不再冤枉人**（v0.1.13）：游戏本体和开服端都有 `Unturned.exe`，
  开服器按 **Steam 的安装记录 → 目录名 `U3DS` → 运行残留要命中两条** 三层来判，
  被本体文件污染过的真开服端照样放行；判错了报错里还带着「(本目录实测: …)」的三条证据
- 🧩 **创意工坊地图直接进地图下拉框**（v0.1.13）：扫描存档 `Workshop\Steam\content\304930\` 里带
  `Map.meta` 的模组，地图名照它同级的文件夹名认，点一下就写入 `Map`；换图之前先把
  **「换地图相当于开新档」**讲明白，用工坊地图开服后还会弹一个 **10 秒的资产包提醒**
- 🧱 **SteamCMD 的两道老卡点都没了**（v0.1.11）：工具本体**直接自带在包里**（不用再下那 757 KB、
  国内经常读到九成就断），而且**中文路径会自动绕开** —— Valve 的 steamcmd 一看到路径里有中文就当场退出，
  以前报错长得像网络问题；现在开服器自己挪到英文文件夹，也会在你填中文位置时提前拦住
- 🎚️ **玩法设置 65 项全部标注原版取值范围、默认值、0 和 1 分别是什么**，超范围不让保存
- 🔧 **想找的设置玩法设置里没有？最底下还有一个默认收起的「高级配置」**（v0.1.14）：
  点开才出现，收着 `Config.txt` 里剩下的 **191 项**（13 个段落 + 关键词筛选 + 记住你上次开没开），
  有自己独立的保存按钮；文件里还没写过这一笔时**会插进对应段落**，不会再"填了却没生效、也没人吭声"
- ⚖️ **换难度之前先弹一张数值对比表**：从普通换到困难，物资、僵尸、经验、空投到底怎么变，点下去之前看得清清楚楚
- 🔎 **开服端版本体检**：本体更新了、开服端没跟上 → 朋友就是连不上；现在直接对比两边版本，一键让 steamcmd 补更新

- 📜 全量操作日志：开服、改配置、登录、报错，出问题一眼定位

- 🚨 **顶栏多了红底白字的「进不去服帮助」按钮**（v0.1.17）：就在「未运行 / 🚀 Rocket 已装」右边，
  点一下直达帮助页那四条报错对照，不用再翻菜单
- 🈶 **中文存档名与中文地图名都认**（v0.1.16）：`Servers` 里已有的中文存档**直接选得中**（别人给的存档包不用先改文件夹名），
  工坊地图和存档 `Level` 里的中文地图名照样识别、照样换图；只有**新建**存档时建议用英文（名字会进开服命令行 `+Secureserver/存档名`）
- 🧭 免道具看世界：无需指南针 / GPS / 手绘地图也能显示方向和打开地图
- 🖼️ 服务器图标与大厅链接（图床）可视化设置，新建存档自动带上默认图标
- 🚀 Rocket 插件框架一键安装与自动检测提醒（v0.1.15 起**按必需文件判装没装**，半装不再报「已安装」；

## 🚀 Rocket 前置插件自动检测

Unturned 服务器默认不带 Rocket。Dawn Sharkk 会在 **创建新服务器存档时** 自动检测
`Modules\Rocket.Unturned`（即游戏自带 `Extras\Install Rocket.bat` 是否执行过）：

- 未安装时网页弹窗提示：**「如需使用更多功能请开启 Rocket 前置插件」**
  - **开启 Rocket 前置插件** —— 自动运行游戏自带的 `Install Rocket.bat` 完成安装
  - **忽略** —— 直接进入开服器，之后可随时点右上角 🚀 徽章或在「服务器设置」页开启
- 点「开服」时若未安装也会询问一次（同一浏览器标签内选过「忽略」后不再打扰）
- 装完把插件 `.dll` 放进 `Servers\你的存档\Rocket\Plugins`，插件配置自动出现在「文件管理」

**v0.1.15 起，"装没装"看的是文件，不是文件夹**（详见上面「控制台通道体检」一节）：
判断依据换成 `Modules\Rocket.Unturned` 里四个必需文件在不在，徽章和仪表盘会写明
「没装好 · 目录里有 1 个文件, 但缺 Rocket.Unturned.dll、…」；
网页点「安装 Rocket」之后**只看真的落地了几个文件**，官方 bat 返回 0 但一个文件没复制的场合不再谎报成功。

## 🔗 关于服务器代码（P2P 联机）

服务器开服后，控制台日志里会出现一行 `Server Code: xxx`。
开服器自动抓取这串代码，**超大字号显示在仪表盘正中央**，一键复制发给朋友，
朋友在游戏里 `Play → 输入服务器代码` 就能直连加入，**不需要端口映射、不需要公网 IP**。

> **严格判定：必须地图加载到 100% 才显示代码。**
> 游戏在 `Loading level: 94%` 时就已经把 `Server Code` 打印出来了，此时世界还没加载完、朋友输代码也进不来。
> 所以开服器抓到代码后会先压着，**直到日志里出现 `Loading level: 100%`** 才放出来显示；
> 每次出现新的 `Server Code` 都会重新走一遍这个判定，**重启过后绝不会继承上一次的代码**
> （万一你的日志里没有加载百分比行，最多 90 秒后也会自动放出，不会卡住）。

> 服务器代码每次开服都可能变化（没有绑定官方服务器 Key 时由 Steam 随机分配），因此**只在服务器运行时显示**：
> 未开服 / 关服后，代码位置会提示「暂时没有启动服务器喔，启动服务器后联机代码会提示在这里」，
> 刚开服时则提示「服务器正在启动, 地图加载到 100% 后代码会出现在这里」，
> 复制按钮同时隐藏，避免误发旧代码。代码框**右上角有「↻ 刷新」按钮**，不想等自动轮询时点一下即可拿到最新代码。
> 担心陌生人进服？在「服务器设置」里设置进服密码即可。
>
> 关于 IP+端口：这种 P2P 服**没有局域网 / IP 直连方式**，IP 直连只适用于 Valve 官方服务器
> （需要在 `Config.txt` 填 Steam 官方 `Login_Token`）。本工具定位方便快捷，只做服务器代码联机，
> 仪表盘因此不再显示局域网地址。

## 🆘 进不去服务器怎么办（帮助页 · 置顶醒目）

「帮助」页**最上方**有一张红边置顶卡片，把日常遇到的四种进服报错逐条对照解决：

- **① 服务器连接超时 / 连接失败** —— 一般是本机网络问题，让进不去的人连着试两次；两次都不行就
  **重启服务器**再发最新代码
- **② 无法验证 Steam 经济 / 连接 Steam 服务器失败** —— 这条**最常见**，和服务器无关，是 Steam 那边一时没连通：

## 🎚️ 玩法设置：每一项都写着该填多大（v0.1.11 起）

以前这一页只有一行说明加一个输入框，填多大全凭感觉 —— 而 Config.txt 里填错一个数，
游戏不会报错，只会静默按你填的跑。现在这一页的每一项都带四样东西：

- **取值范围**：`0~1`、`1~100`、`默认 750` 这种小标签，一眼看到边界
- **默认值**：固定值直接写数；**跟着难度变**的会展开三档，
  例如「默认随难度: 简单 35% · 普通 35% · 困难 15%」
- **0 和 1 是什么意思**：开关项写 `1 = 开启 / 0 = 关闭`，倍率项写
  `1 = 原版速度、2 = 两倍、0.5 = 一半`
- **一段人话说明**：这项影响什么、国内联机建议填多少。
  比如高延迟踢出这项，备注直接写"原版 750 对国内联机太狠了，建议 1500~2000，不然朋友进不来"

**并且不让填错**：

- 输入时当场校验，超范围就在这一项下面出红字
  「物品 · 物品刷新率 最大是 1 (你填了 3)」
- 点保存时后端**整体校验**，只要有一项不合格就**一个都不写**，
  回一句「有 N 项填得不对，这次一个都没写入：……」，把不合规的项逐个标红
- **留空 = 用游戏默认**（跟着难度走）。不确定就别填，比瞎猜一个数字安全得多

顺手纠正了两个**以前标错名字**的项：`Airdrop_Frequency_Min/Max` 原本写作"空投间隔(天)"，
让人以为要填 3 天 7 天 —— 它其实是**倍率**，现在叫
「空投间隔倍率(最小/最大)」，说明里写明"是倍率不是天数"。

## 🩺 网页日志在滚、指令却全发不出去：控制台通道体检（v0.1.15 起）

有一位 **Windows 11 25H2（内部版本 26200.9457）** 的用户反馈了一个特别迷惑的现象：

- 网页上**日志一个字一个字在滚**，看着服务器活得好好的
- 点「刷新玩家列表」、「发送命令」→ `发送失败: [WinError 10061] 由于目标计算机积极拒绝`
- 点「关服」→ 回一句「没有找到本存档的服务器进程」，然后**什么都没能关掉**
- 换个新存档重开、把设置全删掉重来 —— **一点用没有**

最后是他自己手动跑了一遍游戏目录 `Extras\Install Rocket.bat` 才恢复。三条原因叠在一起：

1. **Rocket 只装了一半。** 游戏加载 Rocket 靠的是 `Modules\Rocket.Unturned` 里那几个 dll；
   文件夹**存在但缺文件**时，游戏**一句错都不报**，只是静默地不加载它。
   没有 Rocket 就没有 RCON 端口，于是指令、玩家列表、安全关服**一起废**，而日志照滚。
   旧版开服器判"装没装"用的是"这个文件夹在不在"，所以它一口咬定已安装。
2. **官方安装脚本失败了也返回 0。** bat 里那句 `xcopy` **一个文件都没拷贝，返回码依然是 0**，
   于是"安装完成"和"装了个空目录"在界面上长得一模一样。
3. **Windows 11 新系统把 `wmic` 砍了。** 微软从 24H2 起退役 wmic，精简系统 / 破解镜像里通常直接没有。
   旧版关服的兜底全靠它列进程，列不出来就空着手返回，连那个还开着的黑色窗口都不收。

现在这一版：

- **Rocket 装没装改成逐个数必需文件**（`Rocket.Unturned.dll` / `Rocket.Core.dll` / `Rocket.API.dll` /
  `Rocket.Unturned.module`），少一个就是没装好，并且直接告诉你**目录里现在有几个、缺哪几个**；
  网页点「安装 Rocket」之后**成败只看落地了几个文件**，不信返回码。
  `Extras` 里没有源文件夹的情况会说明"跑脚本也只会复制 0 个文件"，请先在 Steam 验证游戏文件完整性
- **控制台页最上面新增一张「控制台通道体检」卡片**：探端口、数 Rocket 文件、读本存档 RCON 开关、
  比两份日志的新旧、数机器上的 Unturned 进程，然后**按优先级只说最可能那一条** ——
  "端口是通的，那是密码或版本对不上" / "这次服务器根本没加载 Rocket" /
  "机器上已经没有 Unturned.exe 进程了，网页显示运行中只是那个黑色窗口还开着" /
  "Rocket 这次一行日志都没写，最常见是这份开服端里混了游戏本体的文件" /
  "存档里已有的 `Rocket.config.xml` 把我们写的配置盖掉了"
- **发指令、刷新一失败，这张卡片自己就更新**，不用你去点；带「🔍 重新体检」和
  「🚀 修复 Rocket」（直接调官方脚本重装，装完自动复检）
- **删掉了那句「服务器可能还在启动, 等 1 分钟再试」** —— 端口没人监听时等多久都没用，
  这句话把多少人骗得反复等了一下午
- 那行灰色**证据**（端口 / 文件数 / 配置开关 / 两份日志的年龄 / 进程数）会同时写进 `操作日志.txt`，
  **截一张图就能定位**
- **关服兜底不再空手返回**：进程列不出来也照样把控制台中继窗口收掉、`title.tmp` 清掉，
  并告诉你"机器上没有本存档的 Unturned 进程，服务器通常是已经自己崩了，去运行日志看最后几行"
- **`shutdown` 不再被我们提前撕掉连接**：真机两份 `Rocket.log` 里每次 `shutdown` 后面都跟着
  `ObjectDisposedException ... RCONServer.Send` —— 那是我们只等 1.5 秒就 `close()`，
  Rocket 存完盘想把回执写回来，连接已经没了。现在读到"连续没新内容"或服务器断链为止，
  `save` / `shutdown` 这类要先存盘的命令最多给 60 秒，关服等待也从固定 30 秒放宽到盯进程最多 90 秒
- **列进程不再依赖 `wmic`**：PowerShell `Get-CimInstance` → wmic → tasklist 三层依次尝试。
  只有 tasklist 时拿不到命令行，**宁可保守判断也绝不按名字乱杀**，免得误伤正在玩的游戏客户端

## 🔎 开服端版本体检：本体更新了、开服端没跟上（v0.1.11 起）

这是"朋友进不去服务器"最常见又最难自查的原因之一：
游戏本体自动更新到 3.26.5，开服端还停在 3.26.3，版本对不上，
客户端连上去什么提示都没有，只会一直转。

「服务器设置」页顶部现在有一张版本卡片：

- 从**日志里**读版本号 —— 开服端 `Servers\存档名\console.log` 与 `Logs\*.log`，
  本体 `<本体>\Logs\Client.log`。**exe 文件属性上那个版本是 Unity 的版本，跟游戏版本没关系**，
  所以我们只看游戏自己写进日志的 `Game version: 3.26.3.11`
- 两边一致就显示正常；**不一致时红边卡片**，写清开服端哪个版本、本体哪个版本，
  以及"版本对不上时朋友就是连不上"
- 卡片上的按钮直接跑 `steamcmd +app_update 1110390 validate`，
  进度条、速率、百分比在页面里走，**关了页面再回来进度还在**（下载在后端跑，不靠前端计时）
- **不想用这条路**：开服端当初是在 Steam 商店装的，直接在「库 → 按工具筛选」里右键它 → 更新也一样

版本读的是日志，所以**至少开过一次服**才有历史；刚装好还没启动过，
卡片会写"还没拿到版本记录"而不是报错。

## 🗂️ 存档备份与删除（存档管理页）

Unturned 的存档文件是**加密的**，人工打不开也改不了，所以这一页不让你面对一堆 `.dat`：
每个文件都写清了"这是什么存档"，你按名字勾选就够了。路径全部按你选的游戏目录 + 当前存档自动读取。

- **建筑存档** = `Servers\存档名\Level\地图名\`：建筑主体、障碍物（地基墙门）、场景物件、载具、建筑分组、光照
- **玩家存档** = `Servers\存档名\Players\SteamID_0\`：玩家主档、物品栏、技能、生存状态、任务、穿着、动作
- **保存位置自己选**：点「📂 浏览文件夹」逐级挑选（桌面、其他盘、移动硬盘都行），

- **删除一定先备份**：点删除会先把勾选内容完整复制到你所选位置，**备份确认成功后才开始删**；
  备份有任何失败就一个文件都不动
- **只删文件不删目录**：`Level` / `Players` 等文件夹永远保留（空文件夹不影响下次开服）；
  路径越界、非存档文件（`.txt` 等）一律拒绝，防止误删你乱放的东西
- 服务器运行中不允许删档（关服时游戏会把数据写回去），页面会直接提示先关服

## 🖱️ 启动方式：双击 DawnSharkk.exe

大家习惯双击 `.exe`，所以从 v0.1.9 起带了一枚 **`DawnSharkk.exe`** —— 它就是 `启动开服器.bat`
的原生版，做的事一模一样：调用同一个 `python\python.exe`、打开同一个网页、读写同一个
`settings.json`，**不多开任何后台服务，也不往外面发任何东西**。

| | `DawnSharkk.exe`（推荐） | `启动开服器.bat`（备用） |
|---|---|---|
| 下载 / 解压后 | 直接双击就能跑 | Edge 常拦一句「保存此文件有风险」，得点「保留」 |
| 系统安全软件 | 当普通程序，基本不提示 | 自动化 `.bat` 属于常被 Defender 盯上的类型 |
| 长什么样 | 鲨鱼图标 | 记事本图标 |
| 实际做的事 | 调用 `python\python.exe` 跑 `server_manager.py`，弹出命令框 | 完全相同 |
| 怎么关 | 关窗口即退出 | 关窗口即退出 |

两个用的是同一个内核，**哪个顺手用哪个**；哪天真被杀软误删了 exe，`.bat` 立刻顶上，存档和设置都还在。

> 这枚 exe 是拿 Windows 自带的 `csc.exe`（.NET Framework 4.x 编译器）编译的，
> 源码就是同目录的 `launcher.cs`，一百来行，只干「启动 `python\python.exe` 跑 `server_manager.py`」这一件事，
> 谁都可以打开读一遍；要重新编译就执行 `python\python.exe 构建启动器.py`。
> 因为是本地自编译、没买代码签名证书，**第一次运行 SmartScreen 可能仍弹「未知发布者」**，
> 点「更多信息 → 仍要运行」即可。

## 🛒 没有开服端？第 1 步先推你去 Steam 商店装（v0.1.12 起）

开服要的是 Steam 免费提供、但要单独下载的 **Unturned - Dedicated Server**（大家都叫它 U3DS），
和平时玩的 Unturned 客户端**不是同一个东西**。以前你得自己去 Steam「库 → 工具」里翻出来装，
或者让开服器用 steamcmd 替你下 —— 后者这几年修了三个卡点（见下面两节），
但**这些坑 Steam 客户端一个都没有**：下载、校验、以后跟着 Steam 自动更新，全是 Valve 自己的下载器在跑，
**不会卡在 0%，也不管你路径里有没有中文**。所以从 v0.1.12 起它成了首选，steamcmd 退成备用。

初始设置第 1 步的按钮顺序现在是：**「🛒 在 Steam 商店打开开服端 (推荐)」** →
「🔻 用 SteamCMD 下载 (备用)」→「🔄 重新检测本机」。

- **按钮上不印网址**：页面上任何位置都不会出现那一长串链接，跟侧栏的仓库入口一个做法
- **点了不会把这个页面顶掉**：商店开在**新标签页**里，你填到一半的路径、选到一半的存档全都还在，
  切回来接着走
- 商店里点「安装」（免费，不用买、不用激活码）→ 回这一页点「🔄 重新检测本机」→ 下拉里直接选到它
- 它只占 Steam 库里**「工具」那一栏**，和你玩游戏的本体是两个条目，不会搞混
- 本机已经有一份开服端时，卡片说的是"想要一份全新的优先走商店；
  **不想让它进你的游戏库**，再用备用的 SteamCMD"
- 帮助页新增一节「🛒 开服端怎么拿到: 优先用 Steam 商店装」把这几步再讲一遍

## ⬇️ 不想让它进游戏库？备用的 SteamCMD 一键下载

不想占游戏库、这台机器没装 Steam 客户端，就点「🔻 用 SteamCMD 下载 (备用)」——
面板默认收起，点它才展开；只要真开始了任务，面板会自己展开把进度给你看。这条路是让开服器替你下：

- **steamcmd 已经自带在包里**（v0.1.11 起）：直接带一份 Valve 官方的
  `tools\steamcmd\steamcmd.exe`（1.6 MB），点开始就进 1.5 GB 开服端，
  **不再需要先去下那 757 KB 的 zip**（国内连 Akamai 经常读到九成多就断）；
  自带那份被删了才会回退到联网下载，回退路径现在支持**断点续传 + 最多 5 次重试**
- **匿名登录**（`+login anonymous`）：**不登录你的 Steam 账号、不动你的游戏库**
- **位置你说了算**：默认落在开服器自己这个文件夹里（整套绿色便携，不想要了删文件夹就行），
  也能「📂 浏览文件夹」挑到别的盘 —— 在网页里一层层点着选，不用手打路径
- **点下载之前一定再查一遍这台电脑**：真按下「▶ 开始下载」时，后端会重新扫一遍本机
  （注册表里的 Steam 路径 + 各盘常见位置 + 已填的游戏目录旁边）。找到了就弹窗告诉你
  「就用第 1 个 / 仍然下载 / 先不下了」，**不会让你白下 1.5 GB**
- **进度看得见，也能中途停**：百分比、已下 / 总量、实时速度、steamcmd 原始日志滚动；
  「✖ 取消下载」会把整个 steamcmd 进程树结束干净；中途关了网页，重开后进度条自己接着显示
- 下完点「✔ 就用这个开服端，继续第 2 步」，向导立刻跳到选存档

下不动基本都是网络问题（报错里出现 `No license`，或者一直卡在 0%）—— **先开个 Steam 加速器再重试**；
反复都不行就别跟它耗：**回到上面那个商店按钮让 Steam 自己装一次**，再点「🔄 重新检测本机」就能选到。

## 🔻 备用方案 SteamCMD 报「非英文路径」：这一条加速器帮不上（v0.1.11 起已自动绕开）

有用户反馈下载一直卡在 0%，日志里是这两句：

```text
!!! Fatal Error: %appname% cannot run from a folder path that includes non-English characters.
..\steamexe\main.cpp (478) : Assertion Failed: Unable to access Steam files due to incompatible path
```

**这和网不网络完全无关**。Valve 的 steamcmd 在联网之前先扫一遍自己的路径，
只要文件夹名字里有一个非英文字符就直接退出 —— 而中文用户最容易踩的正是这个：
DawnSharkk 放在英文目录，但里面那个 `工具\` 文件夹名是中文，steamcmd 死在自己的安装目录上。

v0.1.11 之后：

- **steamcmd 自己的位置**：包里直接自带一份（`tools\steamcmd\steamcmd.exe`），
  解压到中文文件夹里也会先把自带那份抄到纯英文文件夹再用；
  没有自带时会按顺序挑一个纯英文文件夹（开服器下 `tools\steamcmd` → 各盘符根目录
  `X:\DawnSharkTools\steamcmd`），**不需要你改 DawnSharkk 的存放位置，也不用重装**
- **开服端下到哪**同样避开含中文的路径，默认建议位置一定是英文的
- **你手动填了中文路径**：输入框当场红字提示，后端在下任何东西之前挡回，
  报错里直接写"这一条和网络无关，加速器帮不上"，并给出 `D:\U3DS` 这类可用示例
- **英文文件夹也建不出来**（盘符根目录不让直接写）时不再崩掉，而是告诉你自己建一个再点一次
- 报错分成四类：**路径含中文** / **Steam 一时没递上应用信息（`Missing configuration`，会自动重跑）** /
  **`No license`（这个才是网络或账号问题）** / **其它**，
  以前四种挤在一句"下载失败请检查网络"里，把萌新全带到沟里
- 顺手修掉一个更阴的 bug：**更新本来就能跑的开服端时，目录里早就有 `Unturned.exe`，
  旧代码把"目录存在"当成下载成功**，于是 steamcmd 明明报了 Fatal Error，界面却显示"开服端已更新"。
  现在只有看到官方的 `Success! App '1110390' already up to date.`，或者进度真的跑完并校验过，才算成功

## 🚧 手滑选了游戏本体？现在会被拦下来

Steam 里 **Unturned**（平时玩的本体）和 **Unturned - Dedicated Server**（开服端）是两个独立程序，
但**两个文件夹里都有 `Unturned.exe`** —— 光看这个文件根本分不出来。以前把本体路径粘进第 1 步，
开服器会照单全收：往本体目录里建一个 `Servers\` 文件夹，再用本体的 exe 去跑服务器启动参数，
结果就是游戏直接抛

```text
NullReferenceException: Object reference not set to an instance of an object
  at SDG.Unturned.Assets.Update ()
```

服务器起不来，本体的文件夹里还多出一堆不该有的东西。从 **v0.1.10** 开始这条走不通了：

- **认目录的判据分三层**（v0.1.13，从最硬的证据往下问）：
  ① **Steam 的安装记录** —— 读 `steamapps\appmanifest_304930.acf`（本体，AppID 304930）和
  `appmanifest_1110390.acf`（开服端，AppID 1110390）里记的目录，这份记录用户改不动，命中就一锤定音；
  ② **目录名** —— 叫 `U3DS`（Steam 默认安装名）就放行，除非有 `Unturned_BE.exe`（开服端绝不会有，单独定罪）；
  ③ **运行残留** —— 名字对不上、又不在 Steam 记录里（自己下载或拷贝的）才走到这层，
  要**同时命中两条**才算本体：`Unturned_BE.exe` / `steam_appid.txt` 写着 `304930` /
  同时有 `Worlds` 和 `Preferences.json`
- **为什么要改**（这一条翻的是 v0.1.10 的冤案）：那三条残留全是"跑过一次"留下的痕迹，不是安装标识 ——
  整合包或照教程拷过的开服端混进本体文件后，命中两条就被一直误判成本体。
  现在**只命中一条不定罪，改成黄字提醒照样放行**，Steam 亲装的开服端更是直接放行
- **第 1 步选了本体会直接红字报错**，写清楚是哪条判据命中、为什么不行、下一步该点哪个按钮，
  末尾附「(本目录实测: …)」把三条判据的实测结果和 Steam 记录全列出来 —— **截那一句就能定位**
- **拒绑的目录会写进操作日志**（红色"错误"行），当场没看清还能回去翻
- **之前已经绑到本体上的老用户**：打开会退回初始设置第 1 步，顶部一张红边卡片说明原因，
  原来填的路径留在输入框里方便对照
- **开服按钮也拦一道**：就算 settings.json 被人手改成本体路径，点「▶ 开服」只会得到同一句解释，不会真去启动

## 🏗️ 技术栈

- **纯 Python 标准库** 实现 HTTP 服务（`http.server`），无任何第三方依赖
- 自带官方嵌入式 Python 3.11（`python/` 文件夹），整个文件夹拷到别的电脑也能用
- 前端为服务端渲染的单页应用风格：零构建、零 CDN、离线可用
- 创意工坊查询走 Steam Web API（`ISteamRemoteStorage/GetPublishedFileDetails` + `GetCollectionDetails`），无需 API Key
- 存档备份 / 删除只允许 `Level`、`Players` 子树内的 `.dat` 存档文件：路径越界、目录、其他类型文件一律拒绝，删除前强制完成备份
- `Config.txt` 用嵌套花括号格式，开服器按段落/键定位写入（含 `Browser` 段的 `Links` 数组块），
  只改目标行、注释与其余 1300 多行原文原样保留
- 开服时自动临时启用 Rocket RCON（密码来自本机密钥，仅本机连接，关服自动还原）
- 控制台窗口输出经 `reader.py` 中继，无论是否安装 Rocket 都有完整日志
- 服务器代码有**加载完成门控**：抓到 `Server Code` 后先压住，等日志出现 `Loading level: 100%` 才显示；
  每次开服都从**日志文件末尾**接着读（`Rocket.log` 跨次追加，从头读会把上一局的代码当成当前的）
- 在线玩家列表按 `PlayerID: … Name: … Character: … Ping: …` 逐字段解析，表头行 `Players:` 永远不会被当成玩家；
  给物品 / 传送 / 踢出一律用 **SteamID** 定位，中文玩家名不会再匹配失败
- 地图名会先对齐到 `Maps` / 存档 `Level` 里**真实存在的文件夹名**再写入 `Commands.dat`（小写输入也能纠正）；
  探测不到时保存状态行 + 开服前的黄色 `WARNING` + 操作日志三处提醒，不再"静默退回 PEI"
- 未保存防呆是**纯 vanilla JS**：按卡片 `[data-grp]` 快照每个 input/select 的初值，比对即得"哪几块改过"；
  在 `document` 的**捕获阶段**拦点击（`preventDefault` 早于按钮自己的处理器），保存成功后重放动作；
  各页的保存函数一律返回 Promise，所以"先保存再继续"能真的等到全部写盘成功再切页
- 侧边栏 GitHub 图标是**内联 SVG**（路径取自 CC0 的 simple-icons），连点彩蛋是一段事件委托 + 时间窗计数，
  贡献者名单纯前端拼 DOM —— 不发任何网络请求，断网、离线拷贝到别的电脑也照样能触发
- `DawnSharkk.exe` 用 Windows 自带的 `csc.exe` 现场编译（`launcher.cs` 一百来行，C# 5 语法、零第三方库），
  图标取自 `logo.ico`、版本号从 `VERSION` 自动注入；`构建启动器.py` 负责找编译器、写 manifest、编译、校验
- 开服端下载同样**零第三方依赖**：包里自带 `tools\steamcmd\steamcmd.exe`（`bundled_steamcmd()`
  优先命中，跳过联网）；没有自带时才用 `urllib` 拉官方 `steamcmd.zip`，**带 `Range` 断点续传、最多 5 次重试、
  读超时 25 秒**，解压目标同样逐个过 `ascii_path()` 筛（steamcmd 见到非 ASCII 路径会在联网前就 Fatal Error 退出）；
  进度用正则解析 steamcmd 的 `Update state (…) downloading, progress: x.xx (a / b)`；
  取消走 `taskkill /T /F` 端掉整棵进程树，并用停止标志位挡住"取消后又被写回完成态"的竞态
- **下载成败判定按日志分流**（v0.1.11）：`Fatal Error` / `Assertion Failed` / `no app license` 归硬失败，
  其余 `failed` / `unable to` 归软失败，成功只认 `Success! App '1110390' already up to date.` 或真跑完的进度 ——
  旧版拿"目录里有没有 `Unturned.exe`"当成功依据，更新已有开服端时会把报错说成"已更新"
- **游戏版本只读日志**里的 `Game version: 3.26.3.11`（开服端 `console.log` / `Logs\*.log`、本体 `Logs\Client.log`），
  exe 文件属性那个版本号是 Unity 引擎的，拿来对比只会误判
- **玩法设置参数规格**：`GAMEPLAY_FIELDS` 六元组带 `(下限, 上限, 默认)`，默认值支持 `"mode"` 表示跟随难度；
  `gameplay_check()` 逐项校验、`/api/gameplay` 有一项非法就**整批拒写**并回不合规项列表。
  判"这项用户是否手动设过"用 `str(值).strip() != ""` —— 自动生成时受管理键会被**裸写（无值）**
- **反作弊开关**（v0.1.17）：`ANTICHEAT_KEYS` 是 `{vac: VAC_Secure, be: BattlEye_Secure}` 这一张表，
  `anticheat_on()` 读 `Config.txt` 的 `Server` 段、**读不到就当开着**（默认值方向保守），
  `set_anticheat()` 走 `set_cfg_value()` 写 `"True"/"False"`；`/api/anticheat` 两项一起提交，
  任意一项没写成功就整批报错、并把 `Config.txt 键=结果态` 记进操作日志。
  这两项**已从 `GAMEPLAY_FIELDS` 删掉**（不是隐藏）—— 同一个键两处能改，
  后保存的那一方会静默盖掉前一方；`/api/gameplay` 现在收到 `Server|VAC_Secure` 直接判"不认识的配置项"拒掉
- **启动参数与顶栏红按钮**（v0.1.17）：启动参数卡片复用「高级配置」那套 `<details class="advbox">` 折叠件，
  加一个 `sosbox` 类把它描成帮助页置顶同款红（含浅色主题的另一套底色），开合记忆 `localStorage.ds_launchg`
  与高级配置的 `ds_advg` 各存各的；脏标记的着色条件从"只有 `.card`"放宽成"`.card` 或 `.advbox`"，
  所以折叠块改过没保存也会描黄边。顶栏那颗按钮是 `shell()` 里一个 `<a class="chip sosbtn">`，
  按 `page == "help"` 决定是否输出，不做前端隐藏
- **高级配置（v0.1.14）**：`ADVANCED_SECTIONS` 是 13 段共 **191 项** `(键, 中文名, 类型, 一行说明)` 的规格表，
  `ADV_TYPE_CN` 给类型的中文名，`ADVANCED_DENY` 那 5 项只是接口侧兜底（本来就不在收录表里）。
  `adv_check()` 只挡"会写坏文件"的填法（官方对这批键**没公布范围**，我们不去猜）。
  写入走 `set_cfg_value()`，返回 `set` / `new` / `skip` / `fail` 四态：文件里没有这一笔时由
  `cfg_insert_setting()` 插进对应段落（按 `depth == 0` 只认最外层段落、段名大小写不敏感、
  整段缺失时在末尾补一段）；`/api/gameplay/advanced` 还会把"值本来就是这样"的项跳过并单独计数，
  所以保存提示报的是真实改动数。`cfg_adv_rows()` 读盘前先 `isfile()`，看一眼页面不会凭空建 `Config.txt`
- **三档难度对照**：`DIFF_ROWS`（20 项，数值取自官方维基 Gameplay config）既渲染页面里的折叠表，
  也预序列化成前端 `MODE_DIFF`，换档时弹差异表；点"不换回去了"会把单选还原、`MODE_CUR` 只在确认后更新
- **本体 / 开服端判别**（v0.1.13 改成三层）：`client_dir_reason()` 先查 `steam_install_dirs(appid)`
  （解析 `appmanifest_304930/1110390.acf` 里的 `installdir`，带 120 秒缓存）—— Steam 记录的开服端直接放行、
  记录的本体直接定罪；记录里没有才看目录名 `U3DS`（放行，`Unturned_BE.exe` 例外，它单独定罪）；
  再没有才数 `client_signals()` 的三条运行残留（`Unturned_BE.exe`、`steam_appid.txt` 内容、
  `Worlds` + `Preferences.json` 同时存在），**命中两条才定罪**，一条只出 `client_soft_note()` 黄字。
  残留只是运行痕迹：真机取证过 `steam_appid.txt` 的 mtime 等于那次运行的 Logs mtime，
  所以被本体文件污染的真开服端光看残留会一直误判。`game_exe_ok()` 仍是所有目录入口的唯一关卡 ——
  自动探测、手动粘贴、下载完采纳、`settings.json` 回读全部走它，一处判据处处生效；
  `Servers` / `Modules` / `Extras` 这些两边都有的文件夹特意不用作判据，避免误伤干净的开服端；
  `dir_evidence()` 把三条判据的实测结果拼成一句，跟在报错尾部
- **`steam_appid.txt` 要按行读并把 `\x00` 去掉**：这个文件结尾可能带换行和一个空字节
  （真机核对：开服端里是 `3049300` 后面跟换行加 `\0`，本体里是 `304930`），
  `str.strip()` 去不掉空字节，整行读进来就永远比对不上（`readline().strip("\x00 \t\r\n")`）；
  本体是 `304930`、开服端是 `3049300`，**必须精确相等**才算命中，不能用前缀匹配
- **创意工坊地图**（v0.1.13）：`workshop_maps()` 扫 `存档\Workshop\Steam\content\304930\<数字ID>\`，
  有 `Map.meta` 才把它的**同级文件夹名**当地图（只有 `Object.meta` 的是资产包，不收），
  结果同时喂给 `list_maps()`（所以页面一进就能看到）和 `/api/maps/workshop`（按钮就地重扫）；
  `ws_start_notice()` 只在**开服成功且当前 `Map` 确实是工坊地图**时回一条记录，
  `/api/start` 与 `/api/restart` 一起把它放进 `wsmap` 字段，前端 `wsNotice()` 渲染 10 秒倒计时框；
  工坊内容目录用**本体的 AppID**（304930）命名，不是开服端的 1110390
- **优先推 Steam 商店、steamcmd 当备用**（v0.1.12）：商店网址只写在 `DEDI_STORE_URL` 一个常量里，
  渲染成 `<a class="btn" target="_blank" rel="noopener noreferrer">` —— **页面不出现网址原文**，
  点击开在新标签页、当前向导页不会被导航走（和侧栏仓库入口同一套做法）；
  下载面板 `dlbox` 默认 `display:none`，只有点「备用」按钮或 `dlDraw` 轮询到真有任务在跑时才展开
- **`EDITION` 只保留 `full` 一条路**：模块顶部那一行仍然决定 `LITE` 常量（控制是否渲染下载卡片、
  后端是否放行 `/api/serverdedi/start|cancel`），但从 v0.1.12 起发布只出完整版一个包，
  `发布打包.py` 不再改写这一行；`LITE` 分支留着只为手里还是旧简装包的用户

## ❓ 常见问题

- **双击 `DawnSharkk.exe` 提示「未知发布者 / Windows 已保护你的电脑」？** 点「更多信息」→「仍要运行」。
  这枚 exe 是本地用系统自带的 `csc.exe` 编译的、没有花几百块买代码签名证书，所以 SmartScreen 不认识；
  源码 `launcher.cs` 就摊在同目录里，一百来行，只做「拉起 `python\python.exe` 跑 `server_manager.py`」这一件事。
  实在过不去这道拦，用 `启动开服器.bat` 完全等价
- **`.bat` 被浏览器拦下来 / exe 被杀软删了怎么办？** 文件夹里两个启动方式都带着，另一个双击照用；
  想重新生成 exe 就执行 `python\python.exe 构建启动器.py`
- **第 1 步红字说「这是 Unturned 游戏本体的目录」是什么意思？** 你选的是平时**玩游戏**那个 Unturned，
  不是开服端 —— 两个文件夹里都有 `Unturned.exe`，很容易看错。开服要的是
  **Unturned - Dedicated Server**（U3DS，Steam 里免费）。按提示点「🛒 在 Steam 商店打开开服端」
  让 Steam 自己装一个，装完回来点「🔄 重新检测本机」；不想进游戏库就点备用的「🔻 用 SteamCMD 下载」
- **我这就是正经的开服端，凭什么说我是本体？**（v0.1.13 已修）旧版只看三条运行残留，
  整合包或照教程拷过的开服端里混了本体的 `steam_appid.txt`，凑够两条就被一直拦着。
  现在判据是 **Steam 的安装记录 → 目录名 `U3DS` → 残留要命中两条** 三层，
  Steam 亲装的开服端一命中就放行。要是还被拦，**把报错末尾那句「(本目录实测: …)」截过来**，
  一眼能看出是哪条判据顶住了
- **下拉框里没有我要的创意工坊地图？** 顺序是：「创意工坊」页填模组 ID → **把服务器启动一遍**
  （游戏这时候才会真的去下载地图）→ 回「服务器设置」点**「🧩 识别本存档的创意工坊地图」**，
  地图就出现在下拉框里了，标着「· 🧩 创意工坊 模组ID」。还没下载过的地图下拉框里一定没有它，
  这不是识别失败。另外有些工坊地图还要**另外订阅一份资产包**，
  资产包没到位时地图会加载失败或进去是空图 —— 用工坊地图开服后弹的那个 10 秒框就是提醒这件事的
- **存档名 / 地图名有中文会被认不出来吗？**（v0.1.16）不会。`Servers` 里**已经存在**的存档，
  文件夹叫中文**照样在向导里选得中** —— 别人给的存档包不用先改文件夹名。创意工坊地图、
  存档 `Level` 里的地图名叫中文也一样识别、一样换图；`Name` 那行写中文从 v0.1.0 起就没问题。
  **只有新建存档时仍要求英文**：新名字会原样进开服命令行 `+Secureserver/存档名`，
  而非中文系统的 Windows 上那行中文会被显示成问号，导致"网页显示在运行、关服却关不掉"。
  真碰上就把 `Servers\那个文件夹` 改成英文名，建筑存档和玩家存档都不用动
- **我之前一直绑的就是本体，存档还在吗？** 在。开服器只是往本体的 `Servers\` 里建了个文件夹，
  没动你的游戏文件。把 `...\steamapps\common\Unturned\Servers\你的存档名` **整个剪切**到开服端的
  `Servers\` 下面，重新选一次目录就能接着玩。之前开不了服报的
  `NullReferenceException ... SDG.Unturned.Assets.Update()` 就是这个原因，不是游戏坏了
- **只有一个包了？** 对，**v0.1.12 起不再出简装版**（自带工具才 1.6 MB，不值得让朋友做选择题）。
  手里还是简装版的照常能用，不用重装 —— 详见「📦 只有一个包」
- **电脑里根本没装过开服端（U3DS）怎么办？** 初始设置第 1 步点「🛒 在 Steam 商店打开开服端 (推荐)」，
  商店页点安装（**免费**，不用买、不用激活码），装完回来点「🔄 重新检测本机」直接选到它。
  详见「🛒 没有开服端？第 1 步先推你去 Steam 商店装」
- **为什么把商店推荐在开服器自己下载前面？** 因为 steamcmd 那条路挨过的每一个坑
  （中文路径直接退出、那 757 KB 的工具下到九成断、`Missing configuration`）**Steam 客户端一个都没有**，
  而且它还会跟着 Steam 自动更新。开服器不替你点安装，是因为装到哪、要不要进游戏库该你说了算；
  **不想让开服端出现在你的游戏库**，再用备用的「🔻 用 SteamCMD 下载」—— 匿名下到你自己挑的英文文件夹，
  不登录账号、不进游戏库（详见「⬇️ 不想让它进游戏库？备用的 SteamCMD 一键下载」）
- **那个商店按钮会不会把这个设置页跳走？** 不会。它开在**新标签页**里，而且**页面上不印网址**；
  你在第 1 步填到一半的路径、选到一半的存档都还在，切回来接着走
- **点「▶ 开始下载」弹出一句「本机已经有开服端了」？** 那是**下载前又扫了一遍这台电脑**，
  真的找到了现成的 U3DS —— 点「就用第 1 个」直接接着往下走，1.5 GB 就不用下了；
  你确实想要一份干净的新区，点「仍然下载」即可，两者互不影响
- **下载卡在 0% / 报 `No license`？** 报的是 `No license` 才基本是网络问题：开个 **Steam 加速器**再点一次；
  中途想停就点「✖ 取消下载」，会把 steamcmd 进程树结束干净，下次再点「▶ 开始下载」会续上
- **下载日志里有 `cannot run from a folder path that includes non-English characters`？**
  这一条**跟网络完全无关，加速器帮不上**：Valve 的 steamcmd 只要路径里有中文就直接退出。
  v0.1.11 起开服器会自己挪到英文文件夹，**重新点一次下载就行，不用重装、不用改 DawnSharkk 放哪**；
  你自己填的位置是中文路径时会被当场拦下，改成 `D:\U3DS` 这种纯英文位置即可
- **下载卡在「① 下载官方 SteamCMD」九成就报错（`The read operation timed out`）？**
  那一步只是拿不到 1 MB 的工具，跟 1.5 GB 开服端无关 —— 但国内连 Valve 的 CDN 恰恰最容易半路断。
  **v0.1.11 起包里已经把 steamcmd 自带在 `tools\steamcmd\` 里**，解压出来就能用，整个 zip 下载步骤不再走；
  自带那份被删了才会回退联网下，回退路径现在会**带 `Range` 从断点续传、最多重试 5 次**
- **`ERROR! Failed to install app '1110390' (Missing configuration)`？** 这不是你路径填错，也不是你设置的问题：
  Steam 那一头偶尔第一次不把开服端的**应用元数据**递过来（翻 steamcmd 的 `appinfo_log.txt` 能看到
  一批 `access tokens ... denied`），老版本会把它误报成"多半是网络不通"。
  **v0.1.11 起开服器自己隔几秒重跑，最多三趟** —— 真机复现时第二趟就把 1.86 GB 一路装完；
  三趟都不行再开加速器（卡的是 Steam 的元数据服务器，跟那 1.5 GB 的下载不是一回事）
- **明明报错了，界面却说「开服端已更新」？** 这是 v0.1.10 及以前的一个真 bug：
  更新一个本来就能跑的开服端时，目录里早就有 `Unturned.exe`，旧代码把"目录存在"当成了下载成功。
  v0.1.11 起只有看到官方的 `Success! App '1110390' already up to date.` 或进度真的跑完才算成功
- **玩法设置里那些数字该填多大？** 每一项都标了**原版取值范围**、**默认值**（跟着难度变的会展开三档）、
  以及 **0 和 1 分别是什么**；填超范围会当场出红字，保存时后端整体校验、有一项不合格就一个都不写。
  **不确定就留空** —— 留空等于用游戏默认
- **想调的参数玩法设置里没有？**（v0.1.14）展开页面最底下的**「🔧 高级配置」**，
  那里收着 `Config.txt` 里剩下的 **191 项**（13 个段落，带关键词筛选）。
  它**默认收起**，不点开不影响你；开过一次会记住。改完按它**自己的保存按钮**，重启服务器才生效。
  官方对这批参数**没公布取值范围**，所以这里只拦"肯定写坏文件"的填法，不会拦你填大填小
- **「服务器设置」里的启动参数那一栏怎么不见了？**（v0.1.17）它还在，只是**默认收起、描成红框**了 ——
  那一行写的是「不是开发人员不要动这一块」，**点一下才展开**。里面确实有你要用的「独立控制台窗口」这类正常选项，
  点开照常用；打开过的框会**原样拼进开服命令行**，填错的表现是服务器直接开不起来、朋友进不来、网页看不到运行日志，
  所以不认识的那些就别动它，留默认什么都不影响。开合状态记在浏览器里，下次进来还是你上次那样
- **从普通换成困难，到底改了什么？** 点难度会**先弹一张对比表**列出会变的那几项数值
  （物资刷新率、僵尸血量伤害、经验、空投、昼夜…），点「↩ 不换回去了」选项会自己跳回原档；
  不换难度也想看，就展开「📊 三档难度到底差在哪」，20 项全在里面
- **改了难度为什么某项没变？** 那一行标着 `已手动设为 X` —— 你在玩法设置里单独填过的项，游戏听你填的，不受难度影响
- **朋友连不上、什么提示都没有，一直转圈？** 先看「服务器设置」顶部的版本卡片：
  本体自动更新了但开服端还停在旧版本，**版本对不上就是进不来**。卡片上点一下就能用 steamcmd 补更新；
  当初是**在 Steam 商店装的开服端**，也可以直接在「库 → 按工具筛选」里右键它 → 更新
- **为什么版本从日志里读，不看 exe 属性？** exe 文件属性上那个版本号是 **Unity 引擎的版本**，
  和游戏版本没关系；只有日志里那行 `Game version: 3.26.3.11` 才是真的
- **反作弊能不能关？** 能，但不建议 —— 「服务器设置」页 **🛡️ 反作弊** 卡片上有 **VAC** 和 **BattlEye（战眼）**
  两个勾选框，默认全开（v0.1.17）。取消勾会先弹「关闭反作弊可能不安全，不建议这么做」的确认框，
  点「↩ 还是开着」勾自己弹回去、配置不动；真关了点「💾 保存反作弊设置」再重启服务器。
  关掉的服**不建议公开挂给陌生人**；朋友报「未开启 BattlEye 战眼」进不来时，就是临时关这一项
- **改了配置没生效？** 配置修改后必须重启服务器；改前先关服，否则服务器退出时会写回旧配置
- **改了设置忘了点保存？** 「服务器设置」「玩法设置」现在会**拦下你**：卡片描黄边、右下角提示"有 N 处修改还没保存"，
  切页 / 开服 / 刷新都会弹窗让你选 **💾 先保存再继续** 或 **🗑 取消更改**，不会再白改（详见「🛡️ 改过没保存？防呆拦截」）
- **朋友用代码进不来？** 确认代码是最新一次开服的；双方重启 Steam 再试
- **怎么安全关服？** 点「关服」按钮，会自动保存世界再关闭；强制结束进程才会丢档
- **存档删错了怎么恢复？** 「存档管理」的删除一定会先把被删文件备份到你选的位置 —— 关服状态下把备份里的
  `Level` / `Players` 对应文件复制回存档目录即可恢复
- **Rocket 汉化会不会改掉控制台？** 不会。「一键设置」里的汉化只改指令执行后的反馈文案，控制台与日志不受影响
- **玩家老是迷路？** 打开「一键设置」的 **无需指南针即可显示方向** 和 **无需GPS即可开启卫星地图**，
  不用捡道具也能看方向和全图
- **服务器图标 / 大厅链接去哪设置？** 「服务器设置」页**最底下**那张「🖼️ 服务器图标与大厅链接」卡片
- **服务器图标 / 大厅链接不显示？** ① 必须是 `http(s)://` 开头的**图片直链**（网页浏览地址、带 `?` 的分享链接都不行）
  ② 改完要重启服务器 ③ 图标由玩家客户端下载，玩家访问不了该图床就看不到
- **开服后代码一直显示"正在启动"？** 正常现象 —— 一定要地图加载到 **100%** 才会显示本次代码，
  等十几秒点右上角「↻ 刷新」；重启过后不会拿上一局的旧代码顶替
- **给物品 / 踢出提示找不到玩家？** 用「刷新玩家列表」出来的那一行点按钮（会自动按 **SteamID** 定位）；
  手工敲命令时把玩家名换成那串 17 位 SteamID，中文 name 也不会匹配失败
- **选了别的地图却还是 PEI？** 保存「服务器设置」时下拉框的选择会**真正写入** `Map 地图名`
  （旧版本只认手动输入框，所以下拉框选了没反应）。页面状态行会显示真实地图名，地图名探测不到时
  开服会给黄色警告；真正换图之前会**先弹一个确认框**讲清「换地图相当于开新档」——
  角色与建筑都不跟过去，但老地图的存档还在 `Level\旧地图名` 里，把名字换回去就能接着玩
- **朋友进不去服务器？** 打开「帮助」页**最上方的置顶对照表**：连接超时 / Steam 经济验证 / 战眼未开 / 其他报错，
  四条照着做；特殊问题加开发者 QQ 2497194220 私聊（加好友时写明问题）
- **网页报错去哪看？** 打开「操作日志」页，红色行即错误详情
- **听说有个彩蛋？** 有 —— 在网页界面**快速连点左上角的鲨鱼图标 5 次**，会跳出贡献者名单
